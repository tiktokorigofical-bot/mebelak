# Мебельный сайт без прокрутки

Статический фронтенд на Vite + React. Готов к деплою на Vercel.

## Локальный запуск

1. `npm install`
2. `npm run dev`
3. `npm run build`

## Деплой на Vercel

Vercel автоматически использует `npm run build` для сборки проекта. После сборки готовый сайт будет доступен из директории `dist`.
